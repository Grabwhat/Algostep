Time Complexity Example Explanation
O(1) Array indexing Elements are stored in a block of memory, and the computer only needs a simple equation to calculate the value at an index
O(log n) Binary Search Each step cuts the remaining search space in half
O(n) Looping through an array The loop runs n times, whether n is 10 or 100 billion
O(n log n) Sorting an array There a n! possible arrangements and each comparison of elements cuts the valid arrangements roughly in half. So, you need log2 n! comparisons, which simplifies to n log n.
O(n2) Nested loops Performing n operations n times, so n * n = n2
O(2n) Using recursion for the Fibonacci Sequence Each recursive call branches out into two other recursive calls
O(n!) Generating all permutations You have to go through n! arrangements
