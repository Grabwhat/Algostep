There are no definitive simulation algorithms, since it entirely depends on the problem you are solving. But here are some recommended time complexities for different input sizes:

Input Size Max Time Complexity Allowed Simulation Pattern Allowed
N ≤ 100 O(n3) or O(n4) A lot of brute force/nested checks
N ≤ 500 O(n3) Triple nested loops; checking all combinations of 3 elements
N ≤ 1000 or N ≤ 104 O(n2) Double nested loops; simulating/comparing every pair
N ≤ 2 x 105 O(n log n) Sorting; simulating for trees; a loop using a logarithmic operation
N ≤ 107 O(n) Single pass simulations; two-pointers, sliding windows, single-pass frequency tracking
N > 108 O(log n) or O(1) Math formulas, bitwise simulations; You can't do a linear loop, only math formulas, bitwise tricks, or binary exponentiation
