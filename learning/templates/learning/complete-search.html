There are no definitive complete search algorithms, since it entirely depends on the problem you are solving. But here are some general searching algorithms:

Algorithm Time Complexity Space Complexity Requirements + Notes
Linear Search O(n) O(1) Unsorted arrays, checking item by item
Binary Search O(log n) O(1) Data is sorted; search space is halved each step
Breadth-First Search O(V + E) O(V) Explores layer by layer; V = vertices (nodes), E = edges (connections between nodes)
Depth-First Search O(V + E) O(V) Explores as deep as possible first, then goes back to try other paths (backtracking)
