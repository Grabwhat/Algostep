Variant Time Complexity Space Complexity Description
Fixed O(n) O(1) One iteration through the array, taking in one leading element, and removing one trailing element
Dynamic O(n) O(1) or O(k)* Uses two pointers to expand or shrink the window based on some condition (usually given by the problem)

*The sliding window itself takes O(1) space, but you might use extra (auxiliary) space like hash maps or hash sets to track frequencies or unique items, which might make the space complexity O(k)
